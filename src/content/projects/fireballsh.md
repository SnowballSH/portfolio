# FireballSH

A Discord Bot that Provides Students with 24/7 Math Practice.

## Features

- LaTeX + Asymptote Rendering
- Math Expression Evaluation and Comparison
- Automated Judging System
- Daily Math Puzzles
- Random Math Problem by Subject and Difficulty on Request
- Perfect Squares and Multiplicative Inverses Practices

# GoneuraOu

GoneuraOu is a classical Minishogi engine written in C# with an ELO of about 2150. It uses an advanced, aggressive-pruning version of minimax, including optimizations such as alpha-beta pruning, move ordering, LMR, MVV-LVA, and more. The move generation is optimized using Bitboards.

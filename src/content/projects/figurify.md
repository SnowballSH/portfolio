# Figurify

Written for a virtual hackathon, Figurify is a website that visually demonstrates various algorithms, such as data plotting, sorting algorithms, and minimax.

## Features

- Data Visualization
  - Create downloadable (svg, png, csv), resizable, and interactive graphs with simple clicks.
- Sorting Visualization
  - Figurify shows you the process of your favorite sorting algorithms and explains every step for you.
- Minimax Visualization
  - See how the Minimax AI defeats you in Tic Tac Toe by visualizing its data tree right in your browser.

## Technical Details

The backend is written in Golang for an edge server. The frontend is written using ReactJS.
